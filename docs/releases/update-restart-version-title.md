# Updates direkt installieren und neu starten

Nach einem erfolgreich heruntergeladenen und geprüften Update steht unter **Konfiguration → Automatische Updates** der Button **Update installieren und neu starten** bereit. Die App wird regulär beendet, der Updatehelfer installiert die neue EXE und startet sie anschließend automatisch. Ungespeicherte Einstellungen können zuvor gespeichert werden; beim Abbrechen bleibt die App geöffnet. Ohne diesen Button werden Updates weiterhin beim Beenden installiert.

Ein fehlgeschlagenes Update startet die App nicht automatisch. Falls nur der Neustart fehlschlägt, bleibt das installierte Update erhalten und die App kann manuell gestartet werden.

Die aktuelle Release-Buildnummer steht jetzt direkt im Fenstertitel. Entwicklungsbuilds werden als **Lokaler Build** angezeigt.
