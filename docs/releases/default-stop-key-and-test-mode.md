# Neue Standardwerte für Stopp und Testmodus

Neue Profile verwenden **ENDE** als globale Stopptaste. Der **Testmodus** ist standardmäßig ausgeschaltet und lässt sich unter **Diagnose** einschalten, um den Ablauf ohne Mauseingaben zu prüfen.

Diese Werte gelten auch beim Laden der Standardwerte und für fehlende Felder in Profilen. Bereits gespeicherte Stopptasten und Testmodus-Einstellungen bleiben erhalten.
