### Spielfenster nach Teamaktivierung automatisch öffnen

Nach der Aktivierung über Teambutton oder Teamhotkey wird das passende Spielfenster automatisch in den Vordergrund geholt. Ein minimiertes Spielfenster wird wiederhergestellt. Unter **Konfiguration → Spielfokus** lässt sich das standardmäßig aktive Verhalten ausschalten; mit **Einstellungen speichern** bleibt die Wahl erhalten.

Wenn Windows den Fokuswechsel verhindert oder das Spiel nicht gefunden wird, wartet die aktivierte Teamauswahl weiter auf Spielfokus. Der Hinweis steht im Diagnoseprotokoll.
