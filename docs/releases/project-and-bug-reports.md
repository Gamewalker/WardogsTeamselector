# Herkunft und Fehlermeldungen direkt in der App

**Über die App** ist in der Kopfzeile aus jedem Bereich erreichbar. Das Fenster nennt Gamewalker, die GitHub-Projektquelle, die GNU-GPL-v3.0-Lizenz sowie den aktuellen Release-Build und die Runtime-Variante. Lokale Builds sind ausdrücklich gekennzeichnet.

**Fehler auf GitHub melden** öffnet im Standardbrowser ein vorbereitetes Issue mit Build, Runtime-Variante, Windows-Version und Feldern für Reproduktionsschritte, erwartetes und tatsächliches Ergebnis. Der Button steht auch unter **Diagnose** neben dem Diagnoseexport. Der Bericht wird erst auf GitHub nach Prüfung und Anmeldung abgeschickt; Diagnoseexporte und Screenshots können dort selbst angehängt werden.
